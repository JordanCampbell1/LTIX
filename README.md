# LTIX
LTIX – Low-Latency Trade Ingestion Platform

A distributed Spring Boot platform that:

-   ingests trade orders
    
-   processes them asynchronously
    
-   publishes events to Kafka
    
-   executes simulated trades
    
-   persists results efficiently
    
-   survives partial failures
    
-   scales horizontally
    
-   is observable and debuggable
    
-   deploys to AWS + EKS using Terraform
